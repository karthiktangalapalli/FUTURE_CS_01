# FUTURE_CS_01

## Task 1 – Vulnerability Assessment for a Live Website

### Objective
Conduct a passive vulnerability assessment on a live website to identify potential security weaknesses and provide remediation recommendations.

## Tools Used
- Nmap
- OWASP ZAP (Passive Scan)
- Browser Developer Tools
- GitHub

## Step-by-Step Process

### Step 1: Target Website Selection
Selected a publicly accessible website for security assessment.

### Step 2: Network Reconnaissance
Performed service and port enumeration using Nmap.

Command used:

```bash
nmap -Pn -sV <target-website>
```

### Step 3: Analyze Open Ports and Services
Reviewed:
- Open ports
- Running services
- Service versions

### Step 4: Passive Security Assessment
Configured OWASP ZAP and performed passive scanning while browsing the website.

Activities:
- Browsed website pages
- Captured HTTP/HTTPS requests
- Collected passive security findings

### Step 5: Review Security Findings
Analyzed alerts generated by OWASP ZAP, including:
- Missing security headers
- Information disclosure
- Cookie security issues
- Server version exposure

### Step 6: Browser Inspection
Used Browser Developer Tools (F12) to inspect:
- Network traffic
- HTTP headers
- Security-related configurations

### Step 7: Risk Classification
Classified findings based on severity:
- Low Risk
- Medium Risk
- High Risk

### Step 8: Documentation
Prepared a professional Vulnerability Assessment Report containing:
- Assessment methodology
- Findings
- Risk analysis
- Recommendations
- Screenshots

## Key Findings
- Missing Security Headers
- Information Disclosure
- Cookie Security Misconfiguration
- Server Version Disclosure

## Recommendations
- Implement security headers
- Secure cookies using HttpOnly and Secure flags
- Minimize information disclosure
- Regularly perform vulnerability assessments

## Outcome
Successfully completed a passive vulnerability assessment and documented security findings with remediation recommendations.
